# Security Policy

## Supported Version

Security fixes target the latest commit on `main` and the latest public deployment.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting flow:

<https://github.com/ghassan-ai-projects/scaleshop-scalability-lab/security/advisories/new>

Include the affected version or commit, reproduction steps, impact, and any proposed mitigation. Please allow the maintainer time to investigate before public disclosure.

## Security Scope

The application is a client-side workshop simulation. It has no accounts, application database, production infrastructure integration, or AI grading. Optional progress is stored in the current browser. Hosting and dependency vulnerabilities remain in scope.
