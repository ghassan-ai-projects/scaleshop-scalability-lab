## Open An Issue

Use the [GitHub issue tracker](https://github.com/ghassan-ai-projects/scaleshop-scalability-lab/issues) for:

- reproducible bugs
- accessibility or documentation problems
- clearly scoped feature proposals
- incorrect workshop data or modeled outcomes

Include your browser, operating system, relevant level, actual behavior, expected behavior, and reproduction steps. Remove personal data and credentials from logs or screenshots.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
